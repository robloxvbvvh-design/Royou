# Язык дизайна «как у Apple»

## Принципы
1. **Один посыл на кадр.** Если в кадре два главных объекта — раздели на две сцены.
2. **Воздух.** Минимум 30–40% кадра пустое. Пустота = дороговизна.
3. **Продукт — герой.** Фон тихий, продукт в центре внимания, всё остальное работает на него.
4. **Честность.** Настоящие экраны и цифры. Никаких вымышленных интерфейсов.
5. **Сдержанность.** Один акцентный цвет, одна гарнитура, один тип движения.

## Типографика
- Гарнитура: из `brief.json`; если нет — системная гротеск-семья (Inter / SF-подобная). Не смешивай больше двух начертаний.
- Заголовок: 96–140 px на 1080p, вес 600–700, межбуквенный −1…−2%, межстрочный 1.05.
- Подзаголовок: 40–56 px, вес 400, цвет на 30–40% тусклее заголовка.
- Максимум 7 слов на кадр, максимум 2 строки. Точка в конце фраз-утверждений.
- Для нелатинских языков (кириллица, CJK, арабский, деванагари) подбери гарнитуру с нужными глифами (Noto Sans …) и проверь каждую сцену — длина строк меняется.

## Цвет
- Фон: почти чёрный (#000–#111) или тёплый светлый (#F5F5F7). Чистый #FFF на #000 для основного текста допустим.
- Акцент: 1 цвет из бренда сайта, используется на ≤ 10% площади.
- Градиенты — только мягкие, из тонов бренда, никаких радужных.
- Контраст текста ≥ 4.5:1 (крупный ≥ 3:1).

## Движение
- Easing: `cubic-bezier(0.22, 1, 0.36, 1)` (expo out) для появления, `(0.65, 0, 0.35, 1)` для смены.
- Длительность элемента 0.5–0.9 с; фраза держится ≥ 1.2 с + 0.3 с на каждое слово сверх трёх.
- Появление: сдвиг 24–48 px + opacity, лёгкий blur 8→0. Не вращать, не отскакивать, не «глитчить».
- Камера: медленный dolly/zoom 3–6% за сцену. Не один и тот же зум в каждой сцене — чередуй: статика, панорама, push-in.
- Переходы: cut по ритму, match-cut по форме, плавное растворение. Без «киношных» свайпов и 3D-кубов.

## Раскадровка (шаблон на 30 сек)
1. 0–3 с: тишина → один образ / логотип.
2. 3–8 с: проблема или вопрос, одно предложение.
3. 8–20 с: 3 ключевые функции, по одной сцене, иконка + короткая фраза + реальный экран.
4. 20–26 с: доказательство (цифра, цитата с сайта).
5. 26–30 с: имя продукта + действие («Попробуйте на …»).

## Иконки
- Сетка 24 px (экспорт ×2/×4), безопасная зона 2 px, линия 1.5–2 px, round cap/join.
- Один смысл — одна метафора; без мелких деталей, видимых только при 96 px.
- Заливка — `currentColor`, чтобы иконки перекрашивались темой.
- В анимации иконка рисуется штрихом (stroke-dashoffset), 0.6 с.

## Звук
- Музыка тихая, минималистичная, -22…-18 LUFS под речью; итог ≈ -14 LUFS.
- Озвучка спокойная, средний темп, паузы между сценами 0.3–0.5 с.
- Акцентные звуки (щелчок, мягкий «тап») на появлении ключевых слов, не на каждом.

## Картинки
- Формат: 16:9 для видео, 1:1 и 4:5 для соцсетей, 9:16 для сторис.
- Свет мягкий, направленный, тени читаемые; фон бесшовный или реальная среда без мусора.
- Единый «look» для всех картинок ролика (зерно, температура, контраст).
