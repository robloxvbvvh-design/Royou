# Jova

Чат-ассистент в духе Grok: ответы генерирует реальная языковая модель (не заготовки), текст печатается по ходу, есть поиск в интернете, код, фото, и режим Jova Code для работы с проектом.

## Запуск
```bash
cd jova
export ANTHROPIC_API_KEY=sk-ant-...      # ключ реальной модели
node server.js                           # http://localhost:3000
```
Зависимостей нет, нужен Node 18+.

## Модели и тарифы (config.js)
| Модель | Тариф | Что умеет |
|---|---|---|
| Jova 1.0 | Free | повседневные задачи |
| Jova 2.0 | Free | задачи посложнее |
| Jova 3.0 | Pro | флагман: фото на вход, картинки, видео |
| Jova 4.0 | Pro | сложные задачи, код, учёба |
| Jova 5.0 | Max | самая мощная модель |
| Jova Code | Pro, Max | видит весь проект, читает и правит файлы |

Каждая Jova — это настоящая модель за API. Какая именно, меняется в `config.js` или переменными `JOVA_BACKEND_1..5`, `JOVA_BACKEND_CODE`.

## Токены и лимиты
Считаются реальные токены (вход + выход) × вес модели. У Jova Code ещё ×2, поэтому её лимит кончается быстрее. Есть лимит на час и на неделю (скользящие окна), цифры по тарифам в `config.js`. Остаток виден в боковой панели.

## Поиск, код, медиа
- Поиск и чтение страниц: инструменты `web_search` и `fetch_url`. Без ключа используется DuckDuckGo, с `TAVILY_API_KEY` — Tavily.
- Jova Code работает с папкой `workspace/` (или `JOVA_WORKSPACE`): `list_files`, `read_file`, `write_file`. Выйти за папку нельзя. Команды она не запускает.
- Картинки: `JOVA_IMAGE_ENDPOINT`, `JOVA_IMAGE_KEY` (OpenAI-совместимый `/images/generations`). Видео: `JOVA_VIDEO_ENDPOINT` (POST `{prompt}` → `{url}`). Без этого модель честно сообщит, что генерация не подключена.

## Чего здесь нет
- **Оплаты.** Подписка переключается кнопкой в dev-режиме. При `NODE_ENV=production` переключение закрыто: подключите платёжный сервис, который меняет `plan` пользователя.
- **Входа в аккаунт.** Пользователь определяется случайным id в браузере.
- **Своей обученной нейросети и «нескольких серверов» для Jova 5.0.** Это интерфейс и система тарифов поверх готовых моделей.
