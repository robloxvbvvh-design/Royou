# Jova

Чат-ассистент в духе Grok: ответы генерирует реальная языковая модель (не заготовки), текст печатается по ходу, есть поиск в интернете, код, фото, и режим Jova Code для работы с проектом.

## Запуск
```bash
cd jova
export ANTHROPIC_API_KEY=sk-ant-...      # ключ реальной модели
node server.js                           # http://localhost:3000
```
Зависимостей нет, нужен Node 18+.

## Модели и тарифы (config.js)
| Модель | Тариф | Что умеет |
|---|---|---|
| Jova 1.0 | Free | повседневные задачи |
| Jova 2.0 | Free | задачи посложнее |
| Jova 3.0 | Pro | флагман: фото на вход, картинки, видео |
| Jova 4.0 | Pro | сложные задачи, код, учёба |
| Jova 5.0 | Max | самая мощная модель |
| Jova Code | Pro, Max | видит весь проект, читает и правит файлы |

Каждая Jova — это настоящая модель за API. Какая именно, меняется в `config.js` или переменными `JOVA_BACKEND_1..5`, `JOVA_BACKEND_CODE`.

## Токены и лимиты
Считаются реальные токены (вход + выход) × вес модели. У Jova Code ещё ×2, поэтому её лимит кончается быстрее. Есть лимит на час и на неделю (скользящие окна), цифры по тарифам в `config.js`. Остаток виден в боковой панели.

## Поиск, код, медиа
- Поиск и чтение страниц: инструменты `web_search` и `fetch_url`. Без ключа используется DuckDuckGo, с `TAVILY_API_KEY` — Tavily.
- Jova Code работает с папкой `workspace/` (или `JOVA_WORKSPACE`): `list_files`, `read_file`, `write_file`. Выйти за папку нельзя. Команды она не запускает.
- Картинки: `JOVA_IMAGE_ENDPOINT`, `JOVA_IMAGE_KEY` (OpenAI-совместимый `/images/generations`). Видео: `JOVA_VIDEO_ENDPOINT` (POST `{prompt}` → `{url}`). Без этого модель честно сообщит, что генерация не подключена.

## Чего здесь нет
- **Оплаты.** Подписка переключается кнопкой в dev-режиме. При `NODE_ENV=production` переключение закрыто: подключите платёжный сервис, который меняет `plan` пользователя.
- **Входа в аккаунт.** Пользователь определяется случайным id в браузере.
- **Своей обученной нейросети и «нескольких серверов» для Jova 5.0.** Это интерфейс и система тарифов поверх готовых моделей.

## Собственная модель (без внешнего API)
В `own/` лежит система токенов и нейросеть, написанные с нуля (Python + numpy, без torch):
- `tokenizer.py` — свой байтовый BPE-токенизатор;
- `model.py` — своя нейросеть с ручным обратным проходом, предсказывает следующий токен по окну и по всему вопросу;
- `train.py` — обучение на ваших текстах: `python3 own/train.py --files ваши.txt` (формат блоков `Q: ...` / `A: ...`);
- `serve.py` — сервер, который печатает ответ по токенам.

Запуск:
```bash
python3 own/serve.py &                                   # порт 8765
JOVA_OWN_URL=http://127.0.0.1:8765 node server.js        # Jova 1.0 отвечает своей моделью
```
Ответ генерируется токен за токеном, токены считаются своим токенизатором и идут в лимиты.

**Как отвечает собственная модель.** Она не знает фактов: в обучении остались только приветствия, ответы о себе и о тарифах. На всё остальное сервер сначала ищет в интернете (`TAVILY_API_KEY` или бесплатный DuckDuckGo), читает абзацы найденных страниц, а `own/chat.py` выбирает самые подходящие к вопросу предложения и выводит их токенами своего токенизатора. Ответ показывается в два этапа: сначала цифры (настоящие номера токенов), потом текст, и под ним ссылки на источники.

**Честно про качество.**
- Это не пересказ: ответ собирается из предложений источников, нейросеть он не «понимает». Так сейчас работает поиск у собственной модели.
- Для вопросов, которых нет в обучении, нейросеть сама слова не сочиняет: она обучена на 25 диалогах. Чтобы она писала свои тексты, нужен большой корпус и GPU.
- Контейнер, в котором это писалось, не имел выхода в интернет: поиск проверялся на локальном подставном сервере, с реальным DuckDuckGo или Tavily не запускался.
- Node 18+ по умолчанию не использует переменную прокси. Если хостинг выходит в интернет через прокси, понадобится `--use-env-proxy` (Node 24+) или `undici`.
- Своя модель не работает с инструментами и историей чата.

## Телефон (установка на главный экран)
Сайт — PWA: открывается на телефоне как приложение. После выкладки на хостинг (HTTPS) откройте адрес в телефоне:
- Android, Chrome: кнопка «📲 На главный экран» в меню или «Установить приложение»;
- iPhone, Safari: «Поделиться» → «На экран Домой».
Оболочка сайта кэшируется, поэтому он открывается мгновенно, а чат, конечно, требует сети.
