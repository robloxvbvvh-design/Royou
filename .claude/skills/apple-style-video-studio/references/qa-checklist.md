# Чек-лист аудита (этап 5)

Отмечай каждый пункт: ✅ ок / 🔧 исправлено / ⚠️ осталось (почему). Пиши в `out/qa-report.md`.

## A. Содержание и честность
- [ ] Каждое утверждение, цифра, цена есть на сайте/в брифе.
- [ ] Нет чужих логотипов, торговых марок, знаменитостей без разрешения.
- [ ] Нет выдуманных отзывов, «клиентов», наград.
- [ ] Синтетические люди/кадры помечены в отчёте; не выдаются за реальных.

## B. Безопасность и приватность
- [ ] Покадровый просмотр (contact sheet, каждые 0.5 с): нет токенов, API-ключей, паролей, email, телефонов, адресной строки с секретами, консоли, закладок.
- [ ] Скриншоты сайта очищены от персональных данных (аватары, имена, куки-баннеры).
- [ ] Метаданные файлов очищены: `ffmpeg -map_metadata -1`, у картинок — `exiftool -all=`.
- [ ] Плеер: нет внешних скриптов/шрифтов/трекеров; нет `eval`, нет `innerHTML` с данными из JSON (только `textContent`); путь к файлам из `languages.json` ограничен относительными именами.
- [ ] Имена файлов без личных данных.

## C. Визуальные недоработки
- [ ] Текст не обрезан и не выходит за safe-zone (5%) ни в одном языке.
- [ ] Контраст ≥ 4.5:1 (`scripts/check_contrast.py`).
- [ ] Нет мерцающих краёв, артефактов сжатия на градиентах (при необходимости добавить зерно), чёрных кадров на стыках.
- [ ] Иконки: единый вес, сетка, читаются в 16 px.
- [ ] Шрифты содержат все нужные глифы (нет «квадратиков»).
- [ ] Выдержан один акцентный цвет и одно движение.

## D. «Нейросетевые» артефакты (особенно люди)
- [ ] Руки: по 5 пальцев, естественные суставы и позы.
- [ ] Лица: зубы, глаза, уши, асимметрия, морщины живые; нет «пластикового» блеска.
- [ ] Текст на вывесках/одежде/экранах читается или отсутствует.
- [ ] Свет и тени согласованы; отражения корректны.
- [ ] Нет одинаковых лиц/поз в разных сценах, нет «стоковых улыбок».
- [ ] Нет ползущих деталей и морфинга между кадрами видео.
Любой дефект → перегенерация, ретушь или замена на кадр без человека.

## E. Звук
- [ ] Итоговая громкость ≈ -14 LUFS (`ffmpeg -i f -af loudnorm=print_format=summary -f null -`).
- [ ] Нет клиппинга, щелчков на стыках, музыка не глушит речь.
- [ ] Озвучка произносит названия бренда правильно на каждом языке.

## F. Языки
- [ ] Для каждого языка: перевод по смыслу (не дословный), длина строк влезает, дата/числа/валюта по локали.
- [ ] RTL (ar, he, fa, ur): зеркальная компоновка, `dir="rtl"`, субтитры справа налево.
- [ ] CJK: переносы по символам, межстрочный ≥ 1.2.
- [ ] Субтитры синхронны (±0.15 с), ≤ 2 строки, ≤ 42 знака в строке.

## G. Доступность и совместимость
- [ ] Субтитры есть для каждого языка (WebVTT).
- [ ] Нет вспышек > 3 раз/сек.
- [ ] Плеер управляется с клавиатуры, фокус виден, `prefers-reduced-motion` учтён.
- [ ] mp4: H.264 + AAC, `-movflags +faststart`, воспроизводится в Safari/Chrome/Android/iOS.
- [ ] Размер файла разумный (≤ 25 МБ для 30 с 1080p).
- [ ] `index.html` работает по двойному клику (file://), без сервера.

## H. Итог
- [ ] Просмотрено видео целиком на каждом языке (минимум по контрольным кадрам).
