# Royou Клавиатура

Android-клавиатура (IME): русская и английская раскладки, цифры/символы, Shift/Caps (двойной тап),
повтор Backspace, автозаглавная, вибрация, светлая/тёмная тема, настраиваемая высота клавиш.

## Сборка
- Android Studio: открыть папку `keyboard/` → Run, или
- `gradle -p keyboard assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
- Либо GitHub Actions «Build keyboard APK» → артефакт `royou-keyboard-apk`.

## Установка в настройках телефона
1. Установить APK и открыть приложение «Royou Клавиатура».
2. «Включить в настройках» → включить переключатель Royou Клавиатура.
3. «Выбрать клавиатуру» → Royou Клавиатура.
Долгое нажатие на 🌐 — выбор другой клавиатуры, короткое — RU/EN.
