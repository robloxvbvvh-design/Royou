# Royou Клавиатура

Android-клавиатура (IME), minSdk 26.

| Возможность | Как работает |
|---|---|
| 113 языков | Раскладки в `Languages.kt` + полоса доп. букв. 🌐 — следующий язык, долгое нажатие — список всех |
| Голосовой ввод 🎤 | `SpeechRecognizer` Android на языке клавиатуры, непрерывный, с промежуточным текстом |
| Редактирование ✏️ | стрелки, выделение, всё/копировать/вырезать/вставить, отмена/повтор, удалить слово, очистить |
| Регистр | Shift / Caps (двойной тап), автозаглавная, ПРОПИСНЫЕ / строчные / Каждое Слово / иНВЕРТ / Как в предложении |
| Буфер обмена 📋 | история 40 записей, тап — вставить, долгое — удалить |
| Эмодзи 🙂 | 834 эмодзи в 10 вкладках + недавние + каомодзи |
| GIF | GIPHY (нужен бесплатный ключ в настройках), отправка через `commitContent`, иначе ссылка |
| Перевод 🌍 | выделенный текст/всё поле → любой из 113 языков, «Заменить/Вставить/Копировать» |

## Сборка
- GitHub Actions «Build keyboard APK» → артефакт и релиз **keyboard-latest** (скачивается с телефона), или
- `gradle -p keyboard assembleDebug`, или Android Studio → Run.

## Установка
1. Установить APK, открыть «Royou Клавиатура».
2. «1. Включить в настройках» → включить; «2. Выбрать клавиатуру».
3. «Разрешить микрофон», выбрать языки, вставить ключ GIPHY.

## Ограничения
- Корейский — только отдельные джамо (без сборки слогов), китайский — набор частых иероглифов (без pinyin-IME); для них удобнее голос.
- Перевод использует неофициальную точку Google Translate; GIF — GIPHY API.
- Голос зависит от службы распознавания устройства: не все 113 языков поддерживаются.
